# 🍏 Apple Website Clone

A modern, responsive Apple website clone built using **React** and **Tailwind CSS**.  
This project aims to replicate Apple's clean and elegant design while practicing front-end development skills.

---

## 🚀 Features

- 🎨 Fully responsive layout (mobile, tablet, desktop)
- ⚛️ Built with React (Vite)
- 💨 Styled using Tailwind CSS
- 🧩 Reusable components (Hero, Navbar, Footer, etc.)
- 🌗 Smooth animations and hover effects
- 🖼️ Optimized image sections for Apple products

---

## 🛠️ Tech Stack

- **React (Vite)** — Fast and modern frontend framework  
- **Tailwind CSS** — Utility-first CSS framework  
- **Lucide React / React Icons** — For minimal and clean icons  
- **Git & GitHub** — Version control and hosting
